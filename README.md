# -Private Input
一个轻量的 Windows 桌面悬浮输入框。输入内容默认以不可见字符显示，可通过快捷键临时显示文字，并快速调整窗口显示状态、透明度和主题。
注意：“隐藏显示”不等于加密。请勿把本工具当作密码管理器或安全输入环境。

功能
- 隐藏 / 显示输入内容：默认用不可见字符遮蔽文本，需要时可以切换为明文显示。
- 全局快捷键：可自定义快捷键组合。
- 窗口控制：显示 / 隐藏窗口、切换浅色 / 深色主题、调节窗口透明度。
- 输入操作：支持复制、粘贴、剪切和全选。
- 自动隐藏：可设置明文显示后自动重新隐藏。
- 长按触发：可选择长按快捷键触发操作，并调整长按时长。
- 系统托盘：安装可选依赖后，可以通过系统托盘菜单操作程序。
- 本地设置：快捷键和偏好设置保存在当前 Windows 用户的注册表中。
默认快捷键
功能	默认快捷键
显示 / 隐藏文字	Ctrl + Alt + 2
显示 / 隐藏窗口	Ctrl + Alt + 8
切换浅色 / 深色主题	Ctrl + Alt + 0
增加窗口透明度	Ctrl + Alt + 9
减少窗口透明度	Ctrl + Alt + 7


可以在程序的“设置”窗口中修改快捷键。请留意快捷键可能与其他软件冲突。
下载与使用
使用预编译版本
如果仓库的 Releases 页面提供了 .exe 文件，可以下载后直接运行，无需单独安装 Python。建议只下载此项目官方 Releases 中发布的文件。
从源码运行
运行环境： Windows 10 / Windows 11；建议使用 Python 3.10 或更新版本。程序使用 winreg 和 Windows user32 API，因此不支持 macOS / Linux。
1. 安装 Python，并确保安装时包含 tkinter。
2. 下载或克隆本仓库。
3. 在项目目录打开终端，安装系统托盘相关依赖：
   py -m pip install pystray Pillow
4. 运行脚本。以下假定源文件命名为 private_input.py；若文件名不同，请替换为实际文件名：
   py private_input.py
pystray 和 Pillow 用于系统托盘图标。若不安装它们，程序会尝试以不带托盘功能的方式运行。
隐私与安全说明
- 从当前源码看，输入文本保存在程序运行期间的内存中；程序没有将输入文本写入本地文件或主动发送到网络的逻辑。
- 快捷键和界面偏好设置会保存在当前 Windows 用户的注册表中。
- 使用复制功能时，文本会进入系统剪贴板，其他具有剪贴板访问权限的软件可能读取剪贴板内容。
- 隐藏文本只是界面显示效果，不是加密，也不能防止其他程序读取进程内存或剪贴板。
已知限制
- 目前是 Windows 专用桌面工具。
- 全局快捷键通过后台轮询键盘状态实现；部分快捷键可能与其他软件冲突。
- 系统托盘功能依赖 pystray 和 Pillow。
